# Jeux de données finaux
- anat_archi.csv: 90 lignes : 1 ligne pour chaque individu, avec mesures architecturales et anatomiques.
    Pour l'anatomie : l'année du cerne est spécifié + l'organe sur lequel la mesure a été faite (T = Tige, R = Racine). All = mesure faite sur les 4 années.
    
    
- anat_long.csv: 720 lignes : 1 ligne pour 1 cerne (90 * 2 organes * 4 cernes), avec des NAs si la coupe n'a pas pu être faite / si le cerne est manquant (2 individus ne semblent pas avoir 4 cernes présents).
